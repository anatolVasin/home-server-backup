# home-server-backup

Home page and privacy policy of a private Google login app (OAuth client) that one home server's
rclone uses to store encrypted backups in its owner's Google Drive (scope `drive.file` only).

Google requires both pages before such an app can switch to "In production".

- Home page: https://anatolvasin.github.io/home-server-backup/
- Privacy policy: https://anatolvasin.github.io/home-server-backup/privacy.html
