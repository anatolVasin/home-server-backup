home-server-backup

home-server-backup is a private Google login app (an OAuth client). It lets the backup program rclone on one home server copy encrypted backup files into its owner's Google Drive.

Only the owner of this app uses it, with the owner's own Google account. It is not a public service, and it accepts no other users.

What the app can access

  • Google Drive with the scope drive.file only. The app sees only the files that it created itself. It cannot see, read or change any other file in the Drive.
  • No other Google data: no email, no contacts, no calendar, no profile data.

How the data is protected

The server encrypts every backup before the upload. Google stores only encrypted files that it cannot read.
